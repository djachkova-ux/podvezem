# Подвезём

Веб-приложение (PWA) для взаимного школьного трансфера в загородном посёлке: соседи-водители предлагают свободные места в машине, родители находят, кто отвезёт ребёнка в школу. Без публикации в App Store и Google Play — приложение добавляется на экран телефона из браузера.

## Состояние

Разработка ещё не начата: готовы техническое задание, дизайн-концепт и токены. Следующий шаг — сессия S1 из трекера.

## Стек

React + Vite, Firebase (Firestore, Authentication, Cloud Messaging, Hosting). Вход по телефону и паролю, без SMS-подтверждения. Регистрация открытая, без модерации.

## Дизайн

Палитра «Хвоя»: хвойный `#1F5140` на главное действие, латунь `#B8912A` на служебные акценты, нейтрали подкрашены в зелёный. Шрифты: Golos Text для интерфейса, Oswald для времени и меток. Тёмная тема пересчитана отдельно, а не получена инверсией.
