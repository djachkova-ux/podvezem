# Хэндофф · «Подвезём» (школьный трансфер)

Дата: 03.09.2026. Сессия: **S2 — регистрация, вход, профиль**.

## Что сделано в S2

Полный цикл аутентификации и профиля работает на живом Firebase-проекте.

- **`src/lib/phone.js`** — `digitsOnly`, `isValidPhone`, `phoneToEmail`. Телефон как логин делается через служебный e-mail `<цифры телефона>@transfer.local` (решение записано в ТЗ, раздел 2).
- **`src/lib/auth.js`** — `registerWithPhone`, `loginWithPhone`, `logout`, `subscribeAuth`, `authErrorMessage` (перевод кодов ошибок Firebase на русский).
- **`src/lib/db.js`** — `createUserProfile`, `updateUserProfile`, `subscribeUserProfile` на коллекции `users/{uid}`. Файл будет расти в S3+ (rideOffers, requests и т.д.).
- **`src/lib/constants.js`** — `QUEUES = [1, 2, 3]`.
- **`src/context/AuthContext.jsx`** — `AuthProvider` + `useAuth()`: текущий пользователь и его профиль доступны всему приложению.
- **Экраны:** `Login.jsx`, `Register.jsx` (новые), `Profile.jsx` (переписан с нуля — просмотр/редактирование профиля, роли, авто, дети).
- **`src/components/ChildrenList.jsx`** — добавление/редактирование/удаление детей.
- **`src/styles/forms.css`** — стили полей, чекбоксов-чипов, кнопок, ошибок формы. Подключён в `main.jsx`.
- **`App.jsx`** — гейтинг роутов: неавторизованных уводит на `/login`, авторизованных с `/login` или `/register` — на доску. Без ключей Firebase (`firebaseReady === false`) гейтинг выключен, как и в S1.
- **`firestore.rules`** (новый файл в корне репозитория) — `users/{uid}`: читает и пишет только владелец. Правила уже опубликованы вручную в Firebase Console (Firestore → Rules → Publish), т.к. CLI-деплой ещё не настроен (появится в S12).
- **Проверено в браузере целиком:** регистрация (в т.ч. с включённым «Я тоже вожу») → редирект на доску → профиль показывает данные из Firestore → добавлен ребёнок и авто, сохранено → выход → вход тем же телефоном/паролем → данные на месте. Тестовый аккаунт `+7 900 111-22-33` остался в проекте `podvezyom` (можно удалить в Firebase Console → Authentication → Users, если не нужен).

## Принятые решения (накопительно)

- Стек: React + Vite + Firebase (Firestore, Auth, Cloud Messaging, Hosting). Шаблон «интеграция кефир» здесь **не применяется**.
- Вход: телефон + пароль, **без** SMS — реализовано через служебный email `<цифры>@transfer.local` в Firebase Auth Email/Password (см. ТЗ раздел 2).
- Регистрация открытая, без модерации; задел под роль admin и блокировку в модели данных остаётся, интерфейса нет.
- Палитра «Хвоя», шрифты Golos Text + Oswald.
- Доска — одна вкладка в навигации, две доски внутри переключаются сегментами в шапке.
- `design/tokens.css` — дизайн-референс, `src/styles/tokens.css` — рабочая копия для сборки. Правки нужны в обоих файлах.
- Заказчик регистрируется всегда (адрес + очередь проживания — обязательные поля при регистрации), водитель — опциональный тумблер поверх. Список детей стартует пустым, заполняется в профиле после регистрации.
- При сбое записи профиля в Firestore сразу после `createUserWithEmailAndPassword` аккаунт в Auth откатывается (`deleteUser`), чтобы не плодить «повисшие» логины без профиля.

## На что обратить внимание дальше

- **Тестовый аккаунт в проекте.** `+7 900 111-22-33` / `test1234` остался в Firebase после проверки S2 — не боевые данные, но можно почистить перед показом первым пользователям.
- **Firestore rules для новых коллекций.** В S3–S9 в `firestore.rules` добавятся match-блоки под `rideOffers`, `requests` и т.д. — не забывать публиковать через консоль после каждой правки, пока нет CLI-деплоя.
- **Транзакции в S6.** Подтверждение отклика уменьшает свободные места — только `runTransaction`, иначе два одновременных подтверждения уведут места в минус.
- **Push на iPhone** работает только для приложения, добавленного на «Домой» (iOS 16.4+). Тестировать именно в установленном виде.
- **Размер бандла:** 787 кБ (237 кБ gzip) — Firebase Auth + Firestore. К S11/S12 стоит разнести по чанкам, на мобильном интернете это заметно.
- **SPA-fallback на хостинге.** Прямые адреса вроде `/profile` в dev работают сами; при деплое в S12 в `firebase.json` нужны rewrites на `index.html`, иначе будет 404.
- **Макет не читать целиком** — это ≈40 000 токенов. Смотреть в браузере, цвета брать из токенов.
