- **Git** — репозиторий инициализирован, первый коммит сделан.

## Принятые решения

- Стек: React + Vite + Firebase (Firestore, Auth, Cloud Messaging, Hosting). Шаблон «интеграция кефир» здесь **не применяется** — это не лендинг, а многопользовательское приложение.
- Вход: телефон + пароль, **без** SMS-подтверждения (бесплатно, сообщество закрытое).
- Регистрация открытая, без модерации админом. В модели данных оставляем задел под роль admin и блокировку, интерфейса пока нет.
- Палитра «Хвоя» (хвойный + латунь) выбрана из трёх предложенных вариантов. Переключатель палитр из макета убран.
- Шрифты: Golos Text (интерфейс) + Oswald (время и служебные метки).

## Состояние репозитория

Локальный git-репозиторий создан, ветка `main`, первый коммит на месте. **Удалённого репозитория пока нет:** на машине не установлен GitHub CLI и ни в одном соседнем проекте нет GitHub-remote, то есть доступ к аккаунту здесь не настроен. Что нужно сделать один раз (любой из вариантов):

1. Создать пустой приватный репозиторий на github.com вручную и дать ссылку — тогда останется `git remote add origin …` и `git push -u origin main` (при первом пуше Git Credential Manager попросит войти в браузере).
2. Либо установить GitHub CLI (`winget install --id GitHub.cli`), выполнить `gh auth login`, после чего репозиторий и пуш делаются одной командой.

## На что обратить внимание дальше

- **Транзакции в S6.** Подтверждение отклика уменьшает свободные места — только через `runTransaction`, иначе два одновременных подтверждения уведут места в минус.
- **Push на iPhone** работает только для приложения, добавленного на «Домой» (iOS 16.4+); во вкладке Safari уведомления не приходят. Тестировать именно в установленном виде.
- **Макет не читать целиком** в следующих сессиях — это ≈40 000 токенов. Смотреть в браузере, цвета брать из `design/tokens.css`.
