- **GitHub CLI тоже не в PATH** — вызывать полным путём: `& "C:\Program Files\GitHub CLI\gh.exe"`. Авторизован `djachkova-ux`.
- **Vite слушает только `::1`** на этой машине, если host не задан явно, — из-за этого `localhost` по IPv4 недоступен и браузер не открывает страницу. В `vite.config.js` прописан `host: '127.0.0.1'`. Не убирать.
- **`.claude/launch.json`** запускает dev-сервер напрямую через `node.exe` (не `npm.cmd`: путь с пробелом ломает запуск). Абсолютный путь к node в файле привязан к этой машине.

## На что обратить внимание дальше

- **Транзакции в S6.** Подтверждение отклика уменьшает свободные места — только `runTransaction`, иначе два одновременных подтверждения уведут места в минус.
- **Push на iPhone** работает только для приложения, добавленного на «Домой» (iOS 16.4+). Тестировать именно в установленном виде.
- **Размер бандла:** 700 кБ (212 кБ gzip) — почти всё это Firebase. К S11/S12 стоит разнести по чанкам, на мобильном интернете это заметно.
- **SPA-fallback на хостинге.** Прямые адреса вроде `/profile` в dev работают сами; при деплое в S12 в `firebase.json` нужны rewrites на `index.html`, иначе будет 404.
- **Макет не читать целиком** — это ≈40 000 токенов. Смотреть в браузере, цвета брать из токенов.
